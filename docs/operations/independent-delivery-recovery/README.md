# 기존 지시의 독립 전달 복구

대표 인증을 거친 기존 delivery 한 건에만 선행 순서 예외를 부여한다. 새 지시 생성·자동 승인·총괄 도구 권한 변경을 하지 않는다.

허용 시점과 실제 쓰기 직전에 원문, 직원 세대, 업무 연결, 현재 계약, 승인·개입 대기 및 실행 한도를 대조한다. 변경되었거나 이미 수신한 지시는 다시 쓰지 않는다. 보류된 업무를 재개하는 기능으로 사용하지 않는다.

합성 데이터 검증은 `tests/independent-delivery-*.test.ts`와 `tests/delivery-independent-admission.test.ts`에서 확인한다. 운영 ID·로그·실제 실행 상태를 담은 원 인계 자료는 Git 밖 비공개 운영 기록에 보존한다. 소스 반영은 특정 운영 지시의 수신·업무 완료를 의미하지 않는다.
