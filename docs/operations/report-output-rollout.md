## 반영 범위와 완료 조건

- 업무 대상·행동·근거·남은 조건을 보존하는 공통 작성 기준을 모든 역할에 적용한다. 제목·요약·본문은 각 화면에서 찾기·결정·검토·사용하는 목적에 맞춘다.
- 홈의 현재 상황과 결재 상세에서 판단에 필요한 본문이 기본 표시되도록 한다. 기존 보고·결재 원문을 일괄 수정하거나 승인에 자동 응답하지 않는다.
- 최신 `main`의 실행 복구와 긴 보고 원문 저장 동작을 보존한다. 길이 숫자를 맞추기 위한 축약 안내는 제거하되 명령·인용 대조, 필수 값과 구조 검증은 유지한다.
- 통합 결과의 관련 회귀 검사·브라우저 검사·타입 검사·빌드를 통과한 뒤 커밋하고 작업 브랜치와 `main`을 일반 푸시한다.
- 원격 `main`의 정확한 Git 소스로 릴리스를 빌드하고 서명·격리 기동을 확인한다. 운영 DB·설정·서비스 정의를 백업한 후 웹 서비스만 정상 재시작한다.
- 로컬·Tailscale의 빌드 식별자, 서비스 릴리스의 소스 SHA, 원격 `main` SHA를 대조한다. 기존 데이터 ID, 직원 세션·실행 상태, 동시 실행 설정과 Tailscale 경로 보존을 확인한다.
