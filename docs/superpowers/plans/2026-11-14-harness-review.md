# 하네스 독립 검토 보완 실행 기록

기준: 5fb2786192ede3400bc94f77e4fa64aa803c70ce. 검토 원본: msg_mkAfIP5Vn6x5.
목표: F1~F5 및 출처 표시/백업 P2를 순차 수정하고 재검토 근거를 낸다.
방법: 제공받은 시작 계약·수정 순서대로 직접 실행. 독립 재검토는 기존 w4가 맡는다.
제약: 운영 DB·메인·공용 설정·실제 직원·외부 네트워크 불변. 임시 자료 보존.

- [x] F1: 실제 실패 시험/가림/도움말/다른 위치 반례 → 명령 인자·위치·종료 의미 → 정상 대조군.
- [x] F2: 확인 전 완료 승계 반례 → contract 판정만 승계 → 재검사/재보고 정상 대조군.
- [x] F3: label·옛 업무·갈래 개정 반례 → 현재 확정 계약과 대기 제안 분리 → 확인 뒤 새 판 대조군.
- [x] F4/P2 출처: printf/주석 URL·열지 않은 해석·10/1000 반례 → 실제 읽기 대상 결합·인용 존재와 의미 검토 구분.
- [x] F5: 가짜 비밀 보관/원본/사슬 조회 반례 → 쓰기·읽기 경계 가림·대조/공개 분리·프로젝트 접근 대조군.
- [x] P2 백업: bad/없음/0바이트 반례 → 검증된 백업만 재사용 → 생성/재사용 정상 대조군.
- [x] 필요한 코드 검사·관련 회귀·최신 메인 차이 적용 사본에서 업무 목록 회귀.
- [x] 수정 커밋에 포함할 전후 근거·명령/결과·한계를 정리했다. 자료 게시 결과는 IAMCEO 보고에서 잇는다.

판단: 제공된 실행 계획을 그대로 사용하므로 새 설계 승인 질문을 만들지 않는다.
판단: 관리형 워크트리 도구는 프로젝트 내부 경로를 지정하지 못해 Git으로 내부의 기존 무시 경로에 생성했다.
판단: 시험 정리만 preload에서 막는다. 제품과 시험 단언은 그대로 실행하고 생성한 임시 폴더를 남긴다.

검증 기록:
- 원 기준 하네스 34건 통과(0실패). 최종 수정본 하네스 54건 통과(새 회귀 20건 포함), 실패 0건.
- 저장소·보고 사슬 36건, 백업 정상 2건, 업무 선택 4건, 업무 목록/귀속 5건 통과.
- 코드 검사 종료 0. 원 검토자 probe1~4는 기준/수정본에서 각각 한 번씩 실행했다.
- 원 probe의 가짜 Claude 실행에 cwd 메타데이터만 추가했다. 본문/반례/출력은 보존했다.
- F1 추가 반례: 위치 없는 기록의 추정과 백그라운드 셸 wrapper. 실패 후 수정해 통과했다.
- 최신 메인 사본에서도 하네스 54건·업무 선택 4건·업무 목록/귀속 6건, 코드 검사 종료 0을 확인했다.

판단: 오래된 기록에서 cwd를 추정하지 않는다. 위치 없는 기록은 재검사 대상이다.
판단: 새 미확인 개정안은 확정 판과 분리한다. 갈래의 미확인 제안도 부모 확정 판을 가리지 못한다.
판단: 출처 읽기 어댑터는 확인한 Claude Read/WebFetch만 받는다. 미확인 도구는 출처로 승격하지 않는다.
판단: DB 판은 32를 유지한다. 기존 via에 검사 범위를 적고 반환 시 구조화한다. 옛 verified=true는 의미 검증으로 반환하지 않는다.
한계: 서버의 백업 조회는 실제 파일/해시/DB를 재검증한다. 큰 백업은 조회 비용이 늘 수 있다.
실수와 조치: 강화한 백업 회귀를 처음 실행할 때 보존 규칙이 같은 날의 격리 표본 3개를 지웠다.
운영 데이터·남의 워크트리는 무관하다. 표본 날짜를 이틀 전으로 바꾸고 후속 시험에서 양쪽 백업을 보존했다.
기억 사용: 과거 기억을 새 승인으로 쓰지 않았다. 순차 실행은 현재 원문을 따랐다.
다른 업무의 적용 승인 기억은 범위가 달라 제외했다. 일시정지 기록은 현재 재개 지시가 앞선다.

최종 확인:
- 새 회귀 20건은 기준판에서 정상 대조 1건 통과·19건 실패, 수정본에서 모두 통과했다.
- 최종 소스의 선택 시험은 총 101건 통과·실패 0건이다(하네스 54 + 저장소/보고 36 + 백업 2 + 업무 선택 4 + 업무 목록 5).
- 최신 메인 122bf7878b7cb708ad20932908f868daaae67ed1 사본은 텍스트 충돌 0건, 선택 시험 64건 통과다.
- 최신 메인 사본은 실제 합치기가 아니다. 운영 데이터와 대표 화면은 변경하지 않았다.
- 전체 시험은 돌리지 않았다. 과거 보고의 실패 27건은 이번 선택 범위 밖으로 재검사하지 않았다.
- 긴 비밀 인자를 자른 오류 문구의 가림도 추가로 재현했다. 가린 뒤 자르도록 고쳐 회귀로 남겼다.
- 원 반례의 단독 실패/진짜 pipefail 거절과 정상 성공, 계약 재검사/재보고, 개정 확인 뒤 새 기준, 출처 열람/인용 범위, 백업 생성/재사용을 보존했다.
- 본사 일곱 항목의 미검증과 미지원은 별개로 남는다. 독립 재검토자는 기존 w4이며 작성자 자기 확인만 수행했다.
