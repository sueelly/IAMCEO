# 남은 회귀의 원인을 좁히는 계획

검토판 a75c830과 기준판 5140c39를 보존한다. 새 워크트리에서 제품 코드와 원 기대값을 바꾸지 않고 최소 실패와 환경 소유를 확인한다.

1. 보관 시험의 실제 불일치를 원 출력에서 읽고 단독 사례와 명시적 전달 시도 순서를 대조한다. 세션 재열기 여부와 전달 보류 사유를 구분한다.
2. 옛 herdr 실행 파일의 설치 근거와 고정 설치 정책을 대조한다. 실행 파일 부재로 막힌 35건과 가짜 소켓의 초안 보존 충돌을 분리한다. 임의 실행기 설치·대체는 하지 않는다.
3. 지원 WebKit에서 추가 실패 한 건을 단독·같은 선행 사례와 대조한다. 가짜 실행기의 경로/URL 소유 경계는 실제 fixture로 재현한다. 새 격리 자료를 남기고 운영 세션은 건드리지 않는다.
4. 환경 차단과 관련 실패가 해소된 경우에만 최신 미실행 129개 파일의 마감 검사를 잇는다. 미해소 상태에서는 성공이나 전체 완료로 세지 않는다.
5. 검증한 조사 도구·시험 환경 수정·문서만 커밋하고 별도 작업 브랜치에 일반 올린 뒤 원격 SHA를 확인한다. 원문 연결 거절은 별도 기존 업무에 읽기 결과만 연결한다.

완료 기준은 업무 계약 r2 그대로다. 이 계획은 합격 기준을 줄이거나 보호 정책·제품 생명주기를 변경하지 않는다.
