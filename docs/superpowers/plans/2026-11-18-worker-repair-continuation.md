# 직원의 미완료 업무 재개

**목표** · 직원이 맡은 범위의 미완료 조건을 직접 수정하고, 다른 담당자의 작업이나 권한이 필요한 경우 총괄이 인계한다.

| 요구사항 | 완료 조건 |
| --- | --- |
| R1. 직원은 같은 계약 안에서 고칠 수 있는 실패를 조사하고 수정·재검증한다. | A1. 현재 계약의 진행 보고 또는 보고 없이 끝난 독립 실행을 같은 직원의 업무 재개로 연결한다. 업무 자체는 미완료로 유지하며 보고만 요청하는 새 실행을 만들지 않는다. |
| R2. 총괄은 담당자별로 결과와 완료 기준을 분리하고, 외부 판단이 필요한 막힘 및 반복 실패를 조정한다. | A2. 다른 직원의 검토·통합·적용은 선행 결과를 입력으로 받는 연결 업무로 배정한다. 실제 막힘과 동일 실패 세 번은 총괄이 처리한다. 기존 중단·승인·실행 한도·수신 확인 경계를 보존한다. |
| R3. 직원 수행 완료와 총괄 최종 검수는 각자의 근거로 기록한다. | A3. 미완료 보고는 과거 검사 결과로 완료되는 일을 막고, 현재 판의 합격 근거가 나오면 기존 자동 완료·비동기 검수 흐름을 사용한다. |

## 검증과 구현 순서

- 실제 전달 경로의 격리 검사에서 진행 보고 뒤 원 담당자 재개, 보고 없는 턴, 같은 실패 세 번, 실제 막힘을 확인한다.
- 도구는 현재 계약에서 계속할 직원의 진행 보고를 기록한다. 후속 실행 조정기와 보고 의무는 업무별 수신·계약·중단 기록을 따른다.
- 총괄 역할과 직원 역할, 후속 지시 문구를 갱신하고 관련 검사와 타입 검사로 검증한다.
- 검증된 변경을 작업 브랜치에 커밋하고 원격 SHA를 확인한다.

기존 계약과 완료 기록은 보존한다. 이미 맡긴 업무를 분리할 때 총괄은 승인된 범위를 유지하고 원래 지시를 복제하지 않는다. 실행 횟수와 지시 전달은 저장된 기존 기록으로 확인한다.
