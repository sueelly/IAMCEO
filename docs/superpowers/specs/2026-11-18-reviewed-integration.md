# 남은 구현의 최신 정책 대조와 통합

2026-11-18 사용자는 대기 중인 구현을 직접 검토하고, 조건을 확인해 main과 운영에 반영하도록 지시했다. 총괄은 가장 최근의 모니터링·오케스트레이션 전용 역할을 유지한다.

- R1 [확정]: 총괄 역할 후보를 최신 정책과 먼저 대조한다. 직접 구현·명령 실행·검증·Git 병합·배포·승인 입력을 허용하는 옛 역할은 반영하지 않는다.
- A1 → R1: `docs/operations/conductor-role-policy.md`, 실제 도구 목록과 제공자 실행 제한을 대조하고 기존 역할 회귀 및 설치된 Codex의 격리 도구 검사가 통과한다.
- R2 [확정]: 취소·대체된 후보, 이미 반영된 패치, 검토용 백업을 새 기능으로 합치지 않는다. 나머지 후보는 고정한 소스판에서 검사하고 필요한 문제를 수정한다.
- A2 → R2: 후보별 소스 SHA, 현재 조건, 반영·제외 이유와 실제 검사 결과를 기록한다. 미검증 결과를 완료로 보고하지 않는다.
- R3 [확정]: 전달 복구·보류·업무 순서·실행 증거와 신규 화면은 최신 실행 계약과 권한 제한을 보존한다. 확인되지 않은 입력 재전송·완료 판정·결재 응답은 하지 않는다.
- A3 → R3: 동일 입력 중복·전송 직전 조건 변경·실제 cwd 이탈·기존 업무 상태·승인 및 데이터 보존 회귀를 통과한다.
- R4 [확정]: 검증한 변경만 커밋·작업 브랜치 일반 푸시·최신 main 통합·일반 푸시 후 정확한 SHA의 릴리스를 배포한다.
- A4 → R4: 원격 SHA·운영 빌드·로컬/Tailscale 준비 상태가 일치하고 기존 DB ID·대화 세대·실행 터미널·설정·경로를 보존한다.

대상은 IAMCEO의 독립 실행 복구, 승인/연결 게이트 후속 수정, 검사별 실행 위치 연결, 팀 요약/지도, Agent-A 직접 화면 후보다. 임시 공동 총괄은 최신 취소/대체 기록에 따라 제외한다. 오래된 체험판·Codex 이전 후보·이전 백업은 현재 납품과 동일하지 않아 자동 통합하지 않는다. 다른 작업의 워크트리와 미커밋 변경은 그대로 둔다.

검증이 환경이나 외부 연동에 의존하면 그 조건을 실제로 확인한다. 확인 불가·명시적 취소·최신 정책 충돌은 제외 근거이지 통과가 아니다. 완료된 코드 검사와 실제 운영 검증을 구분한다.
