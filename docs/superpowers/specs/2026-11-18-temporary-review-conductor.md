# God 임시 공동 총괄

대표는 God of the world의 총괄 검수 병목을 해소하기 위해 이번 대기열을 처리할 공동 총괄 한 명을 추가하고, 처리 후 제거하도록 지시했다. 모델은 gpt-6-astra, effort xhigh, Fast다. 기존 총괄은 유지한다.

R1: 대표 인증 API로 기존 총괄이 있는 프로젝트에 임시 공동 총괄 한 명을 생성한다. 요청은 같은 프로젝트의 대표 원문과 작업 ID를 참조한다. 기존 단일 총괄 경로는 유지하고 추가 총괄은 한 명으로 제한한다.
A1→R1: 유효한 대표 글에서 생성한 세션은 conductor 권한으로 검수 확정·위임 도구를 갖고, getConductor는 기존 총괄을 반환한다. 다른 프로젝트의 글, 직원 글, 없는 작업·총괄, 중복 추가는 거절한다. 같은 원문 재요청은 기존 추가 총괄을 반환한다.

R2: 모델·effort·병렬 선호를 생성 시 적용한다. Fast는 기존 CLI의 공식 설정과 실제 화면으로 검증한다.
A2→R2: 실행기에 gpt-6-astra/xhigh 설정이 전달되고 일반 직원 10명의 한도를 소비하지 않는다. 다른 직원의 설정은 바뀌지 않는다.

R3: 원본 총괄의 durable context 전체를 private 인계물로 보존하고 검수 대기 목록을 고정한다. 새 총괄은 원문 기록과 현재 인계의 차이를 읽고 분리된 검수 범위를 처리한다.
A3→R3: 프로젝트 메시지·업무·계약·판정·결정·자료와 native transcript의 개수·해시·원본 위치를 확인한다. 모든 기록에 접근할 수 있다는 사실과 모델 문맥 창에 동시에 들어갔다는 주장은 구분한다. 키·토큰·다른 프로젝트 기록은 인계에서 제외한다.

R4: 이번 검수 목록과 그로부터 생긴 재검수 조건이 해결되면 결과를 기존 총괄에게 인계하고 임시 총괄을 명부에서 제거한다.
A4→R4: 대기/미확정 입력·열린 결정·실행이 없고 인계가 실제 수신됐을 때만 정식 close 경로를 사용한다. 보고·자료·원본 세션은 보존한다. 미해결을 완료로 기록하거나 승인을 자동 응답하지 않는다.

구현 선택: 기존 addMember의 conductor kind와 정식 세션 수명주기를 재사용하고 대표용 임시 총괄 생성 경로만 추가한다. 배포는 기존 릴리스 절차에 따라 현재 CLI들을 보존해 수행하며 다른 진행 작업의 릴리스를 덮지 않는다.
